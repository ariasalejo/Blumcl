# 🧩 BLUMCL — Componentes

## Core
Coordina el funcionamiento general de Blumcl.

## Scanner
Recopila información sin modificar el sistema.

## Storage
Analiza almacenamiento y archivos.

## Memory
Analiza RAM, swap y procesos relacionados.

## CPU
Analiza carga y consumo del procesador.

## Apps
Analiza aplicaciones y paquetes accesibles.

## System
Analiza información general del entorno.

## Analysis
Interpreta los datos obtenidos.

## Cleaner
Ejecuta acciones de limpieza previamente aprobadas.

## Reports
Genera informes JSON, HTML e imágenes.

## AI
Conecta Blumcl con la IA local.

## UI
Gestiona la interacción con el usuario.

## Utils
Contiene funciones auxiliares reutilizables.
