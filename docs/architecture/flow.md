# 🔄 BLUMCL — Flujo del Sistema

## Flujo principal

```text
📱 TELÉFONO
     ↓
🚀 BLUMCL
     ↓
🔬 SCANNER
     ↓
📊 EVIDENCIA
     ↓
🤖 IA LOCAL
     ↓
🧠 INTERPRETACIÓN
     ↓
📋 INFORME
     ↓
💡 RECOMENDACIÓN
     ↓
👤 CONFIRMACIÓN
     ↓
🧹 LIMPIEZA CONTROLADA
     ↓
📊 INFORME FINAL
```

## Principio

Blumcl debe separar claramente:

- descubrimiento;
- análisis;
- recomendación;
- acción.

## Regla fundamental

NO ANALIZAR = NO LIMPIAR
NO EXPLICAR = NO EJECUTAR
NO CONFIRMAR = NO MODIFICAR

## Objetivo

Proporcionar al usuario información suficiente para comprender
qué encontró Blumcl y qué pretende hacer antes de modificar el sistema.
