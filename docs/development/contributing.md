# 🤝 BLUMCL — Contribución

## Principio

Blumcl debe ser comprensible, reproducible y seguro.

## Antes de modificar

1. Comprender la arquitectura.
2. Revisar la documentación.
3. Ejecutar las pruebas.
4. Identificar el módulo afectado.

## Después de modificar

1. Ejecutar pruebas.
2. Ejecutar comprobación de sintaxis.
3. Revisar cambios con Git.
4. Actualizar documentación cuando corresponda.
5. Registrar decisiones importantes.

## Código

Las funciones deben tener responsabilidades claras.

La seguridad debe preferirse frente a la comodidad.

## Idioma

El proyecto utiliza español como idioma principal.
