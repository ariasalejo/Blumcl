# 🌎 BLUMCL — Política de Idioma

## Propósito

Blumcl nace como un proyecto hispano y su idioma principal de
desarrollo, documentación e interfaz será el **español**.

La prioridad actual es construir una experiencia clara, natural y
profesional para usuarios hispanohablantes.

---

## 🇪🇸 Idioma principal

El idioma oficial de Blumcl en su etapa actual es:

**Español**

Esto incluye:

- interfaz de terminal;
- mensajes del programa;
- menús;
- advertencias;
- confirmaciones;
- recomendaciones;
- documentación;
- informes;
- nombres visibles para el usuario;
- tutoriales;
- ejemplos;
- mensajes de seguridad.

---

## 🧠 Principio

Blumcl debe ser:

> **Simple por fuera. Sofisticado por dentro.**

La complejidad técnica debe permanecer principalmente en la
arquitectura interna.

La interfaz debe utilizar un lenguaje que una persona pueda
comprender sin necesidad de conocimientos avanzados de programación.

---

## 🚫 Evitar inglés innecesario

No se utilizarán términos en inglés cuando exista una expresión
clara y natural en español.

Ejemplos:

| Evitar | Preferir |
|---|---|
| Scanner | Escáner |
| Cleaner | Limpieza |
| Report | Informe |
| Snapshot | Instantánea |
| Evidence | Evidencia |
| Audit | Auditoría |
| Settings | Configuración |
| Warning | Advertencia |
| Cancel | Cancelar |
| Delete | Eliminar |
| Confirm | Confirmar |
| Dashboard | Panel |
| History | Historial |

---
