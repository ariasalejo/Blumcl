# 🧪 BLUMCL — Pruebas

## Objetivo

Cada módulo importante debe poder comprobarse automáticamente.

## Categorías

### Pruebas unitarias

Comprueban funciones individuales.

### Pruebas de integración

Comprueban la comunicación entre módulos.

### Pruebas de seguridad

Comprueban:

- rutas protegidas;
- confirmaciones;
- cuarentena;
- validación;
- comportamiento ante errores.

### Pruebas de regresión

Evitan que nuevas versiones rompan funcionalidades existentes.

## Regla

Una funcionalidad importante no se considera terminada hasta tener
una prueba adecuada.
